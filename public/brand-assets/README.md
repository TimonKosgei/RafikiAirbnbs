# Brand assets

Add the image files to this folder using these exact names:

- `favicon.ico` — square favicon, ideally 32x32 or 48x48 pixels.
- `apple-touch-icon.png` — optional square PNG, 180x180 pixels, for Apple devices.
- `og-image.png` — Open Graph/social sharing image, 1200x630 pixels (1.91:1).

The HTML metadata is already configured to use these paths. For reliable social previews after deployment, change the `og:image` and `twitter:image` values in the root `index.html` to the absolute URL, for example `https://your-domain.com/brand-assets/og-image.png`.
